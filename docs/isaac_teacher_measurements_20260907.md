A practical minimum for the first session is priorities 1 plus a sensor baseline at every selected arm start. Aim for millimetre-scale geometry measurements and gram-scale mass readings where the instruments support them; report the actual uncertainty instead of rounding an estimate into a measurement. If there is time for only one calibration improvement after dimensions, prioritize the camera-to-base transform and pad/TCP transform.
