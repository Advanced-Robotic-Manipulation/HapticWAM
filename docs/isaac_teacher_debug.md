The first pickup exposes an additional tactile/contact problem. PhysX supplies a sparse manifold on each inward pad face. Its corner points can fall outside the assumed active ellipse even when the supported contact patch spans the sensor interior. The point filter therefore reports nearly zero gel load during a physical grasp. The native 2.5 N bilateral grip latch remains unarmed. At 15.764 s the historical terminal veto replaces a squeezing command with the measured aperture 0.55152; preload disappears and the object drops. The raw proposal also contains loosening commands, so the veto is not established as the exclusive cause; the native latch would preserve preload against either source. This diagnosis motivates an explicit manifold-area coverage approximation, with its uncertainty and force conservation tested separately. In the first patch-coverage run, both trailing gel loads first exceed 2.5 N at 12.628 s (3.894/3.889 N), preserving commanded closure 0.628721. At 12.652 s the next delivered plan requests 0.574748, while execution retains the squeeze. Reconstruction from delivered plans reproduces every non-stopped accepted command, including 631 ticks that suppress reopening.
