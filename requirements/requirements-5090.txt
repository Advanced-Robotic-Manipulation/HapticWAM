# Data collection, deployment, DAgger rollouts, evaluation.
#
# Install (fresh machine, Python 3.10-3.12 venv recommended):
#     python -m venv ~/venvs/phantom && source ~/venvs/phantom/bin/activate
#     pip install -r requirements/requirements-5090.txt
#     pip install -e .                      # from the repo root
#
# NON-PIP steps (do these too):
#   1. dmrobotics SDK (DM-Tac W2L) — vendor install per Daimon's instructions;
#      verify with:  python -c "import dmrobotics"
#   2. librealsense udev rules (RealSense over USB without root):
#      https://github.com/IntelRealSense/librealsense/blob/master/doc/distribution_linux.md
#   3. SpaceMouse: sudo apt install libhidapi-hidraw0 libhidapi-libusb0
#      + a udev rule for the 3Dconnexion vendor id (or run pyspacemouse as root once to test)
#   4. Add your user to dialout for serial access: sudo usermod -aG dialout $USER
#   5. NVIDIA driver >= 570 (Blackwell/sm_120 support)
#
# Verify sequence after install (see docs/launch_guide.md):
#     pytest tests/ && python -m phantom.scripts.mock_smoke
#     python -m phantom.scripts.smoke_test --synthetic --device cuda   # VRAM measurement
#     python -m phantom.scripts.verify_backbone --save-ref ref_shim.pt

# --- PyTorch: Blackwell (sm_120) needs a build that CARRIES sm_120 ----------
# 2026-09-19: bumped 2.7.1 -> 2.13.0 to clear four GitHub advisories against
# torch <= 2.12.1. The cu128 index stops at torch 2.11.0, so the index moves
# to cu129 — still CUDA 12.x, hence minor-version compatible with the >= 570
# driver this box already runs (cu130 would demand >= 580). The cu129 x86_64
# wheels are built for sm_{75,80,86,90,100,120} (pytorch v2.13.0,
# .ci/manywheel/build_env_setup.py::TORCH_CUDA_ARCH_LIST_TABLE), i.e. they
# cover the 5090 AND the H100/A100 clusters; the cu126 wheels stop at sm_90
# and are NOT an option here.
# Matching pair: torch 2.13.0 + torchvision 0.28.0.
